# InteractNet chart motion

Browser compositions built with Remotion Player. Run `npm ci` followed by `npm run build` from this directory to rebuild assets/motion/charts.js.

Evidence: paper Table 33 reports paired-state probe separation of 91% versus 68% without latent-state input; recurrence probes 89% versus 57% without event-chain input. These are diagnostic probe results, not estimates of human psychological accuracy. Table 4 supplies the stage score ranges. Remaining compositions reproduce matched-information and architecture-gain comparisons.

Each loop is 210 frames at 30 fps. Frame-driven reveals leave complete values visible for most of the loop. The Player pauses outside the viewport and when the tab is hidden; reduced-motion preferences show the completed chart. Production uses an automatically playing embedded Player without transport controls. All original model and case data remain in their existing files.

Mechanism compositions illustrate an observed reply versus inferred state hypotheses, progress versus recurrence on a turn axis, and acknowledgment versus an initiative/check/follow-through sequence. They are authored conceptual examples, separate from the paper-derived empirical plots beside them.
